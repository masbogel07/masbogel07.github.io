👋 What is spicy-cli?

spicy-cli is a small tool that runs in a text window on your computer. Instead of clicking through a website, you type short instructions and press Enter. The tool then talks to SpicyAPI for you and brings back the results.

You do not need to write any code, install a programming language, or understand how APIs work. If you can type a word and press Enter, you can use spicy-cli. It is built for Windows and is designed to stay out of your way — one window, a few commands, and your files appear in a folder you choose.

People use it because it is fast, repeatable, and keeps their hands on the keyboard. You can queue up a batch of images, convert a picture into a short video clip, or check the price of a job before spending anything — all without opening a browser tab.

✨ What you can do with it

Everything below is done by typing a single line and pressing Enter.

  • Inspect models: See a live list of the AI models SpicyAPI offers, what each one is good at, and which ones are switched on for your account.
  • Get a quote first: Ask for the price of a job before you run it, so there are no surprises.
  • Generate images: Turn a written description into a finished picture.
  • Text to video: Describe a scene and receive a short video clip.
  • Image to video: Give the tool a picture and let it animate it into motion.
  • Download results: Save finished images and videos straight to a folder on your PC, with tidy file names.
  • Batch friendly: Repeat a job as many times as you like without re-typing everything from scratch.
Tip: nothing is generated until you confirm. Use the quote step first if you want to keep an eye on costs.

💻 Before you start

You only need a few basic things in place. There is nothing technical to configure.

  • A Windows 10 or Windows 11 computer.
  • An internet connection.
  • A SpicyAPI key, which you receive when you sign up with SpicyAPI. Think of it as a password that lets the tool use your account.
  • Around 100 MB of free disk space for the tool and a folder to keep your generated files.
  • About five minutes of your time for the first setup.

You do not need Node.js, TypeScript, or any developer software installed separately — spicy-cli is prepared so that everyday users can simply download and start.

🚀 Your first run

spicy-cli runs in the Command Prompt — the plain text window that comes with Windows. Opening it takes two clicks.

  1. Press the Windows key on your keyboard.
  2. Type Command Prompt and press Enter. A black or dark blue window appears.
  3. Type spicy-cli and press Enter. If the tool is installed correctly, you will see a short welcome message and a list of available commands.
  4. Add your SpicyAPI key once, using the setup command described below, so the tool remembers it for next time.
  5. Type spicy-cli models and press Enter to confirm everything is connected.

If you see a list of models appear, you are finished with setup. Everything after this point is just typing what you want.

⌨️ The commands you will actually use

You do not have to memorise anything. Type spicy-cli on its own at any time and the tool will remind you what is available.

What you type What it does
spicy-cli models Shows every AI model you can use, with a short description of each.
spicy-cli quote Tells you what a job will cost before you run it.
spicy-cli generate Creates an image or video from your written description.
spicy-cli download Saves the finished result to a folder on your computer.
spicy-cli --help Brings up the full list of options in plain language.

Any time you are unsure, add --help after a command — for example spicy-cli generate --help — and the tool will explain the choices in simple terms.

🔧 If something goes wrong

The window says the command is not recognised

Close Command Prompt completely and open it again. Windows sometimes needs a fresh window before it notices a newly installed tool. If it still happens, run the download file once more and let it finish.

The tool says my key is missing or wrong

Your SpicyAPI key is a long string of letters and numbers. Copy it exactly, without extra spaces at the beginning or end. Paste it into the setup command, press Enter, and try the models command again.

A generation is taking a long time

Video jobs take longer than images, sometimes several minutes. Leave the window open and do not press Ctrl+C — that cancels the job. You can keep using other windows while it works.

I cannot find my finished file

The tool prints the full location of every file it saves, right there in the window. Highlight that line, press Enter or copy it, and paste it into the address bar of File Explorer to jump straight to the folder.

Windows shows a warning when I open the file

This is a standard Windows message for downloaded files from smaller projects. Click "More info", then "Run anyway". Only do this if you downloaded from the releases link shown on this page.

❓ Common questions

Do I need to know how to program?

No. You type a command, press Enter, and read the result. That is the whole workflow.

Does this work on a Mac or a phone?

spicy-cli is prepared for Windows computers. Phones and tablets are not supported.

Will it cost me anything to download?

Downloading the tool is free. Usage costs come from SpicyAPI itself, which is why the quote command exists — check the price before you commit to a job.

Where do my files go?

Wherever you tell the tool to save them, or the default folder it shows you on first run. Nothing is uploaded anywhere except the requests needed to generate your result.

Can I run several jobs in a row?

Yes. Repeat the generate command as often as you need, or change the wording slightly to explore different results.

How do I update to a newer version?

Return to the releases page, download the newest release, and run it the same way you did the first time. Your saved key and settings stay where they are.
